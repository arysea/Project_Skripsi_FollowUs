# Project_Skripsi_FollowUs
Sistem katalog fashion online Follow Us berbasis web yang dikembangkan untuk memenuhi kebutuhan Tugas Akhir. Sistem ini menyediakan katalog produk secara dinamis serta fitur pengelolaan produk, kategori, banner, foto produk, dan stok melalui halaman admin. Pemesanan produk dilakukan melalui WhatsApp.
